# Worked Example

A fictional team's feedback over four sprints. It illustrates both sides of the same trap: similar wording hiding different causes, and different wording hiding the same cause.

- [Read the source log](log.md): four fictional feedback entries
- [Read the saved output](output.md): an illustrative pattern review
- [Read what held up and what did not](review.md): the groupings, missing checks and unsupported wording

The repository doesn't record which model wrote this output, the exact run instructions or settings, or whether it knew the intended answer. Read it as an illustration with limitations, not as a logged model test.
